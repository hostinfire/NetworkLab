# Keyboard reference

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New topology |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+D` | Duplicate selected device |
| `Ctrl` + click | Add/remove device from multi-selection |
| `Ctrl+P` | Ping selected device |
| `Delete` | Delete selected device |
| `Escape` | Cancel placement or connection tool |
| `F1` | Open Help Center |
| `Space` | Pause or resume an active simulation replay |
