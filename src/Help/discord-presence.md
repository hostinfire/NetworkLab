# Connect Rich Presence

Rich Presence uses Discord Desktop's local IPC connection.

1. Open **Tools > Discord Rich Presence**.
2. Choose **Developer Portal** and create a Discord application.
3. Copy its numeric **Application ID** and enter it in Northstar.
4. Keep Discord Desktop running; Northstar reconnects if Discord restarts.

Presence shows the project name and current selection or simulation event. It does not upload or share topology files, addresses, or device configuration. Choose **Disconnect** in the settings window to clear the saved ID and disable the integration.

If Discord does not show the activity, verify the desktop client is running, that the saved ID belongs to your application, and that activity status is enabled in Discord settings.
