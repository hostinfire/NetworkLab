# Topology workspace

Click a library item, then click an empty canvas area to place it. Drag a device to move it; Ctrl-click devices to select multiple, then drag to move the group. **Snap to grid** aligns the group to the canvas grid. The zoom slider changes scale, **Fit view** frames the current device layout, and the scrollbars pan around the canvas.

## Connections

Choose a cable type beside **Connect**, then click two different devices. The simulator prefers the selected interface on the first device and chooses the first unused interface at the other end. Right-click a device for duplicate, connect, group, and delete actions. Right-click empty canvas for quick-add choices or an annotation. Use **Annotate** to add a canvas note; double-click to edit and right-click to remove it.

## Search and editing

Use **Find** to search device names, kinds, and IPv4 addresses. **Undo** and **Redo** keep a bounded history of topology edits. `Ctrl+D` duplicates the selected device; `Delete` removes it and its links.
